## 📦 Mindfactory Bulk Cart Add - Tampermonkey Script

Ein Tampermonkey-Script, das es ermöglicht, mehrere Artikel per Artikelnummer gleichzeitig in den Mindfactory-Warenkorb zu legen.

### Features

- ✅ Bulk-Import mehrerer Artikel
- ✅ Mengenangabe pro Artikel
- ✅ Fortschrittsanzeige
- ✅ Einfache Bedienung
- ✅ Nutzt vorhandene Mindfactory-Formulare

### Schnellstart

1. **Tampermonkey installieren** ([Chrome](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) | [Firefox](https://addons.mozilla.org/de/firefox/addon/tampermonkey/) | [Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd))
2. **Script kopieren**: `mindfactory-cart-bulk-add.user.js`
3. **Bei mindfactory.de nutzen**: Button erscheint unten rechts

### Verwendung

```
1234567        → 1x Artikel 1234567
9876543:2      → 2x Artikel 9876543
1357924:5      → 5x Artikel 1357924
```

Einfach Artikelnummern eingeben (eine pro Zeile) und auf "Artikel hinzufügen" klicken!
